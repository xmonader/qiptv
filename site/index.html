Open source · Linux desktop

Xtream Codes IPTV, as a proper desktop app.

qiptv signs in to your IPTV provider and lets you browse live TV, movies and series by category, then plays them with libmpv. It's native Qt 6 and C++, with no browser engine and no Electron.

Install View source on GitHub

What it does

Everything you need to watch, and nothing that gets in the way.

BROWSE

Live TV, movies and series

Pick a section and a category. Channel logos and posters load in the background, and typing filters the current list.

ACCOUNTS

Multiple profiles

Save several providers or accounts. qiptv signs back in to the one you used last.

PLAYBACK

libmpv underneath

Hardware decoding where available, seeking on movies and episodes, volume up to 150%, and fullscreen with controls that hide themselves.

KEEP WATCHING

Next and previous that make sense

Next and previous follow the list you started from. Channels wrap around, and episodes carry on into the next season. When an episode finishes, the next one starts.

SERIES

Seasons and episodes

A series page with the plot, a season picker and the episode list. Double-click to play.

DESKTOP

Tray, media keys, notifications

An optional close-to-tray mode, "Now playing" notifications, and media keys that work while qiptv has focus.

Install

qiptv is built from source. On Debian and Ubuntu you can package it as a .deb in one command and install that, so it upgrades and uninstalls cleanly.

1. Get the dependencies

A C++17 compiler, CMake ≥ 3.20, Qt ≥ 6.5 and libmpv.

# Debian / Ubuntu
sudo apt install build-essential cmake \
  qt6-base-dev libmpv-dev \
  debhelper dpkg-dev fakeroot

2. Build and install a .deb

The build runs the test suite, then you install the resulting package.

git clone https://github.com/xmonader/qiptv
cd qiptv
make deb
sudo apt install ./dist/qiptv_*.deb

Or just run it

Build and run straight from the source tree, without installing anything.

make build
make test
make run

qiptv is MIT licensed. It's for IPTV services you're legally entitled to use, and it ships no content and no provider credentials.
